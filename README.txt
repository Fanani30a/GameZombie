ZOMBIE HEROES
Bahasa: HTML, CSS, JavaScript (tanpa library)

Cara menjalankan: buka index.html di browser (Chrome/Edge/Firefox). Tidak perlu install apa pun.
Internet hanya dipakai untuk font Bungee (judul); tanpa internet tetap jalan dengan font cadangan.

Struktur:
  index.html     - kerangka halaman, menu, tombol
  style.css      - tampilan menu dan overlay
  game.js        - seluruh logika game, animasi, dan musik (Web Audio)
  assets/teman.png - gambar teman yang harus ditolong

Kontrol: WASD gerak, mouse bidik, klik tahan / Spasi tembak, P jeda.
